# 下班前三件事（会话收尾清单）

> 用法：复制到你的项目，写进规范文件强制每次会话结束前执行。
> 为什么：AI 不会自己"下班收拾工位"——没关的程序和满地的临时文件，会在第二天互相干扰（真实事故来源）。

---

## 收尾三件事（每次开发会话结束前）

- [ ] **1. 关闭所有运行中的程序**：开发服务、后端进程全部关闭，后台严禁留进程
- [ ] **2. 清理临时产物**：临时测试文件、备份文件、临时导出一律删除
- [ ] **3. 清理构建缓存残留**：构建工具的缓存目录里如有中断残留（如 `*_temp_*` 文件），删除

## 新会话开工自检（第二天开工前）

- [ ] 检查端口无残留进程占用：

```bash
# Windows（Git Bash / CMD）
netstat -ano | findstr <你的端口号>

# macOS / Linux
lsof -i :<你的端口号>
```

- [ ] 确认无输出（端口空闲）再启动服务

## 一次性脚本管理

- 数据修复类脚本必须标注"一次性执行"注释
- 执行后保留留档，**不重复执行**

---

> 本清单来自真实事故：多个开发服务实例并存导致状态互相污染，排查耗时数小时。
